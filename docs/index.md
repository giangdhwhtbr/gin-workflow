# gin-workflow

gin-workflow is a plugin for Claude Code, Codex CLI, Antigravity CLI, OpenCode, and GitHub Copilot CLI. It takes a change from requirement to merge through recorded gates: discuss, plan, orchestrate, execute, ship. Nothing is merged without your approval, and a `/quick` path handles small changes.

## Where to start

- [Getting started](getting-started.md): install the plugin and run one feature from idea to merge.
- [Team roles](roles.md): what a PM, a BA, a developer, and a tester each do and read.
- [Starters](starters/greenfield.md): the [greenfield](starters/greenfield.md) and [brownfield](starters/brownfield.md) entry points.
- [Guides](guides/use-cases.md): use cases, recommended tools, Windows, team mode, and the QA and BA add-ons.
- [Reference](reference/skills.md): every skill, CLI command, and configuration key.

The source and issue tracker live on [GitHub](https://github.com/giangdhwhtbr/gin-workflow).
