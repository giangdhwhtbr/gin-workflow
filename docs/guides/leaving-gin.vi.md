# Rời gin { #leaving-gin }

Spec, plan, knowledge và Beads của bạn vẫn đọc được khi không có gin. Chỉ có git hook là gây cản trở, và `gin hooks uninstall` gỡ chúng. Chạy lệnh này trước khi gỡ gin khỏi máy.

Bảng dưới liệt kê mọi thứ gin để lại trong project, chúng ra sao khi gin không còn, và cách gỡ.

| Thứ gì | Khi không có gin | Cách gỡ |
|---|---|---|
| Git hook `pre-commit` và `pre-push` | Bị chặn: mỗi hook dừng với `gin is not on PATH; run ./install.sh`, nên mọi commit và push đều thất bại | Chạy `gin hooks uninstall` trước khi gỡ gin. Hoặc xóa hai file mang dòng `generated by gin hooks install` trong thư mục mà `git rev-parse --git-path hooks` in ra |
| Khối từ `<!-- gin:start` đến `<!-- gin:end -->` trong `AGENTS.md`, và dòng `@AGENTS.md` trong `CLAUDE.md` | Vẫn đọc được, nhưng khối này bảo agent chạy `gin` | Xóa khối và dòng đó |
| `.agent-workflow/` và `.ginrc` | Không còn được dùng | Xóa chúng |
| `.planning/` (spec, plan, roadmap, knowledge, review) | Markdown đọc được | Giữ lại hoặc chuyển đi |
| Ref checkpoint review `refs/gin/review/<bead>` | Vô hại | `git update-ref -d refs/gin/review/<bead>` ở máy local, và `git push origin :refs/gin/review/<bead>` trên remote |
| Worktree dưới `.planning/worktrees/` | Là worktree git thông thường | `git worktree remove <path>` |
| Beads | Chạy được không cần gin; bằng chứng của các gate nằm trong metadata của từng epic | Không có gì để gỡ |
| File của chế độ team: `CODEOWNERS`, mẫu pull request, `.githooks/commit-msg`, và job CI mà `gin team init` đã ghi | Vẫn hoạt động; `commit-msg` là shell script không cần gin | Xóa chúng để dừng các quy ước |
| Plugin trong từng harness | Vẫn còn đăng ký | Xem mục cuối |

## Gỡ hook { #remove-the-hooks }

`gin hooks uninstall` gỡ hai hook mà `gin hooks install` đã ghi và giữ nguyên mọi hook khác. [Tham chiếu CLI](../reference/cli.md#gin-hooks) mô tả các trạng thái in ra và mã thoát. Trong workspace, chạy `gin hooks uninstall --all-repos` từ thư mục cha.

## Gỡ plugin { #remove-the-plugin }

`./install.sh --uninstall` gỡ các launcher, output `dist` đã sinh, skill và agent OpenCode trong `~/.config/opencode`, và đăng ký Copilot. Lệnh này để lại bản cài theo project (`.opencode/` của một repository) và các đăng ký Claude Code, Codex, Antigravity.

Gỡ chúng bằng tay hoặc bằng lệnh plugin của từng harness. Với Claude Code, xóa `~/.claude/skills/gin` và mục `gin@skills-dir` dưới `enabledPlugins` trong `~/.claude/settings.json`.
