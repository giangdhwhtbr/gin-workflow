# Leaving gin

Your specs, plans, knowledge, and Beads stay readable without gin. Only the git hooks get in the way, and `gin hooks uninstall` removes them. Run it before you remove gin from the machine.

The table lists everything gin leaves in a project, what it does once gin is gone, and how to remove it.

| What | Without gin | To remove |
|---|---|---|
| Git hooks `pre-commit` and `pre-push` | Blocked: each hook stops with `gin is not on PATH; run ./install.sh`, so every commit and push fails | Run `gin hooks uninstall` before removing gin. Or delete the two files that carry `generated by gin hooks install` from the directory `git rev-parse --git-path hooks` prints |
| The block from `<!-- gin:start` to `<!-- gin:end -->` in `AGENTS.md`, and the `@AGENTS.md` line in `CLAUDE.md` | Readable, but the block tells agents to run `gin` | Delete the block and the line |
| `.agent-workflow/` and `.ginrc` | Unused | Delete them |
| `.planning/` (specs, plans, roadmap, knowledge, reviews) | Readable Markdown | Keep it or move it |
| Review checkpoint refs `refs/gin/review/<bead>` | Harmless | `git update-ref -d refs/gin/review/<bead>` locally, and `git push origin :refs/gin/review/<bead>` on the remote |
| Worktrees under `.planning/worktrees/` | Plain git worktrees | `git worktree remove <path>` |
| Beads | Works without gin; the gate proofs stay in the metadata of each epic | Nothing to remove |
| Team mode files: `CODEOWNERS`, the pull request template, `.githooks/commit-msg`, and the CI job `gin team init` wrote | They keep working; `commit-msg` is a shell script that needs no gin | Delete them to stop the conventions |
| The plugin in each harness | Still registered | See the last section |

## Remove the hooks

`gin hooks uninstall` removes the two hooks that `gin hooks install` wrote and leaves any other hook as it was. [The CLI reference](../reference/cli.md#gin-hooks) gives its output states and exit codes. In a workspace, run `gin hooks uninstall --all-repos` from the parent.

## Remove the plugin

`./install.sh --uninstall` removes the launchers, the generated `dist` output, the OpenCode skills and agents in `~/.config/opencode`, and the Copilot registration. It leaves project installs (a repository's `.opencode/`) and the Claude Code, Codex, and Antigravity registrations.

Remove those by hand or with each harness's plugin command. For Claude Code, delete `~/.claude/skills/gin` and the `gin@skills-dir` entry under `enabledPlugins` in `~/.claude/settings.json`.
