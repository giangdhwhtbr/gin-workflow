Strangler Fig Architecture: Monolith to Modern Stack

Incremental migration pattern eliminating single-point-of-failure risks.

BEFORE: Legacy Monolith (JDK 8) Decommissioning in progress
Presentation: JSP & Scriptlets
/webapp/auth/login.jsp
Issues: Business logic mixed with HTML, vulnerable to XSS
Controller: Raw Java Servlets
UserAuthServlet.java (HttpServlet)
Issues: Manual session clustering, stateful HttpSession, tight Tomcat coupling
Security: Legacy MD5 + Salt Hash
Custom SecurityFilter.java
Issues: Outdated cryptography, non-standard authorization
AFTER: Modern Cloud-Native Stack Zero-downtime Strangler Facade
Frontend: React 19 + TypeScript + Vite
apps/web/src/features/auth/AuthForm.tsx
Benefits: Componentized UI, Action Hooks, type-safe contract
Backend: Spring Boot 3.3 (Java 21)
services/backend/src/.../AuthController.java
Benefits: Stateless JWT, Spring Security 6, OpenAPI contracts
Security: Argon2id + Dual-Verification Upgrade
Argon2PasswordEncoder.java
Benefits: Verifies MD5 on first login and silently upgrades hash to Argon2id
