💡 Under the Hood: How Detection & Multi-Subrepos Actually Work in Gin-Workflow
Automated Heuristics (project_detect.py): gin-workflow setup detect scans for standard manifests (like root package.json, pnpm-workspace.yaml, pyproject.toml, turbo.json).
Handling Polyglot Multi-Subrepos (Java + Node + Playwright): In a complex modernization monorepo with diverse sub-repos (as-is/, backend/, frontend/, qa/), detect identifies the repo as stage: brownfield. The team then explicitly maps each sub-repo to a governed area using team.areas in .agent-workflow/config.yaml. This guarantees 100% deterministic isolation without fragile auto-guessing.
