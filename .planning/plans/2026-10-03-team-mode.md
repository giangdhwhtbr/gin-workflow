# Plan: Team Mode (Sub-project E)

**Goal:** A team (for example BA, QE, BE/FE devs, BE/FE leads) can run the gin-workflow lifecycle on one repository: every member is identified by git email, gates that need another person's approval are proven by a merged (or approved) PR/MR reviewed by someone holding the configured role, tracks are assigned by area and owner, and conventions are generated once and enforced locally and in CI. A repository without a `team:` key behaves exactly as today.

**Architecture:** Opt-in `team:` block (schema 2.7). Five modules in `workflow_core/`: `team.py` (config model, semantic validation, git-email identity, plan track parsing, approval policy, record/waiver authorization), `team_host.py` (`PrInfo` from `gh` or `glab`), `team_init.py` (generated CODEOWNERS, PR/MR template, commit-msg hook and shim, CI, doctor section), `team_beads.py` (ready, claim, external placeholders, Dolt sync), `team_cli.py` (`gin-workflow team`). `lifecycle_cli.py` calls `team.py` from `record`, `unblock`, and `state` only when `team:` exists. Stage skills hand off to an on-demand `gin-team` skill; `/gin-workflow:team-setup` onboards leads and members.

**Tech Stack:** Python 3.12 stdlib (`subprocess`, `re`, `argparse`, `dataclasses`, `urllib.parse`) + PyYAML/jsonschema (already required); `git`; `gh` or `glab`; `bd` 1.0.x and `dolt` 2.x for Beads sync; `unittest`; POSIX sh hook; Markdown skills; bash/PowerShell installers.

**Spec:** `.planning/specs/2026-10-03-team-mode-design.md` @ `8b3bef9` (workflow id `team-mode`, `requirement_confirmed` recorded).

| Conventions | `gin-workflow team init [--ci] [--force]` generates CODEOWNERS, PR/MR template, `commit-msg` hook, optional CI. Enforced locally (hook via `core.hooksPath`) and on the server (CI, branch protection). |
| Hosts | GitHub (`gh`) and GitLab (`glab`), behind one `fetch_pr(url) -> PrInfo` interface. |
| Unknown identity | In team mode, a git email not in `team.members` can run read commands (`state`, `specs`, `rules`, `doctor`) but `record`, `unblock`, and track claims exit 2. |

## Deviations from the spec (decided while planning; each keeps the spec's intent)

1. **Hook activation.** `bd init` sets `core.hooksPath` to `.beads/hooks`; setting it to `.githooks` (spec §5) would silently disable the Beads hooks. A new `gin-workflow team hooks` writes a marked shim `commit-msg` into the active hooks directory (`git rev-parse --git-path hooks`) that execs `.githooks/commit-msg`; it refuses (exit 1) when a foreign `commit-msg` is there. Doctor's `hook` check looks for that shim.
2. **Lost claim race.** Spike (two clones, bare git remote): when two members claim the same bead, the losing `bd dolt pull` stops with a Dolt merge conflict, so "pull again" (spec §4) cannot work. `team claim` syncs first, so the only unpushed change is the claim; when the push is rejected it resets local Beads to the remote (`dolt fetch origin && dolt reset --hard origin/main` in the embedded data dir from `bd dolt show`) and exits 1 naming the holder.
3. **Empty remote.** A git repository used as the Dolt remote must already have one commit (verified); the first `bd dolt pull` against it reports `no branches found`, which `team sync` treats as nothing to pull. New members bootstrap with `bd init --remote <url>`.
4. **Fifth module** `team_beads.py` (Beads operations) beside the four in spec §2, and the `team hooks` subcommand.
5. **GitLab approvals** carry no commit id, so `verification_passed` on GitLab checks that the MR head equals local `HEAD` and that a listed role approved; whether a push resets approvals is the project's GitLab setting.
6. **Area overlap** is checked on literal glob prefixes (the text before the first `*`, `?`, `[`): two areas overlap when one prefix starts with the other.
7. **`project.team`** is added to `gin-workflow state` by `lifecycle_cli` (it needs the git email), not as a `ProjectSettings` field.
8. **CI** runs `team codeowners --check` and `specs lint` only when the repository variable `GIN_WORKFLOW_INSTALL` holds an install command; the commit-message check is plain shell and always runs.
9. **Plan PR detection** also accepts an SDD `<change>/plan.md` (the `gin-sdd` skill writes plans there).

## Requirement Analysis
- Problem: gin-workflow assumes one actor: gates take a free-form `--actor`, events and Beads are local, and nothing proves that the BA or a lead approved a spec or plan, who owns which track, or that commits follow a shared convention.
- Success: spec §Testing items and the Validation list below.
- Constraints: opt-in; solo unchanged; enforcement lives on the git host (CODEOWNERS, branch protection) and the CLI verifies it; deterministic CLI; no secrets in config.
- Non-goals (spec): Bitbucket; configuring branch protection through host APIs; several teams per repository; ownership per REQ-ID; sharing workflow events; G (`gin-qa`).

## Approach Options
### Option 1: Git host as shared truth, optional Dolt sync (selected in discuss)
- Pros: real enforcement through CODEOWNERS/branch protection; no new infrastructure; solo unchanged.
- Cons: two host CLIs to support; lead progress comes from plans and PRs unless Beads sync is on.
### Option 2: Shared Beads as the only shared state
- Cons: role checks stay advisory, every member needs Dolt remote access, claim races without host proof.
### Recommended Approach
- Option 1 with `team.beads_sync`, as confirmed.

def git(root: Path, *args: str) -> str:
    return subprocess.run(["git", *args], cwd=root, check=True, capture_output=True, text=True).stdout


def make_team_repo(root: Path, *, email: str = "binh@corp.com", host: str = "github", team: str | None = None,
                   extra: str = "") -> Path:
    root = Path(root)
    root.mkdir(parents=True, exist_ok=True)

    git(root, "config", "user.email", email)

    body = TEAM.format(host=host) if team is None else team
    (root / ".agent-workflow/config.yaml").write_text(f"schema_version: '2.7'\n{extra}{body}", encoding="utf-8")
    return root


def write(root: Path, relative: str, text: str) -> Path:
    path = Path(root) / relative
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(text, encoding="utf-8")
    return path

    bin_dir.mkdir(parents=True, exist_ok=True)

    path = bin_dir / name
    path.write_text(FAKE.format(python=sys.executable), encoding="utf-8")

def calls(bin_dir: Path) -> list[list[str]]:
    log = Path(bin_dir) / "calls.log"
    if not log.is_file():
        return []
    return [json.loads(line) for line in log.read_text(encoding="utf-8").splitlines()]

          body: str = "") -> dict:

        "reviews": [{"author": {"login": login}, "state": review_state, "commit": {"oid": commit}}

        "files": [{"path": item} for item in files], "body": body,

def validate_team(raw: Mapping[str, Any]) -> list[str]:
    """Semantic rules the JSON schema cannot express; every finding is returned."""
    errors: list[str] = []
    members = raw.get("members") or {}
    areas = raw.get("areas") or {}
    held: set[str] = set()

        key = str(email).strip().lower()
        if key in emails:
            errors.append(f"team.members: duplicate email {email} (also {emails[key]})")
        emails[key] = str(email)
        login = str(spec.get("login", "")).lower()
        if login in logins:
            errors.append(f"team.members: login {spec.get('login')} used by {logins[login]} and {email}")

    needed: list[tuple[str, str]] = []

        if isinstance(policy, list):
            needed += [(role, f"team.approvals.{gate}") for role in policy]
    for name, area in areas.items():
        needed.append((area.get("lead", ""), f"team.areas.{name}.lead"))
        needed += [(role, f"team.areas.{name}.roles") for role in area.get("roles", ())]

def _parser() -> argparse.ArgumentParser:
    common = argparse.ArgumentParser(add_help=False)
    common.add_argument("--repository", type=Path, default=Path.cwd())
    common.add_argument("--format", choices=("text", "json"), default="text")
    parser = argparse.ArgumentParser(prog="gin-workflow team")

def _emit(payload: dict[str, Any], output_format: str, text: str) -> None:
    print(json.dumps(payload, indent=2, sort_keys=True) if output_format == "json" else text)


def _run(args: argparse.Namespace) -> int:
    from .configuration import resolve_effective_config

    root = args.repository.resolve()
    if not (root / ".agent-workflow/config.yaml").is_file():
        raise team_core.TeamError("gin-workflow setup is required; run /setup once")
    config = resolve_effective_config(root, write=False).config.to_dict()

                                  "(/gin-workflow:team-setup)")
    member = team_core.require_member(root, team)
    payload = {"email": member.email, "login": member.login, "roles": list(member.roles),
               "areas": team.areas_for(member)}
    _emit(payload, args.format, f"{member.email} ({member.login}) roles: {', '.join(member.roles)}; "
                                f"areas: {', '.join(payload['areas']) or '-'}")
    return 0

    try:

from __future__ import annotations

class HostUnavailable(Exception):
    """The host CLI is missing, unauthenticated, or unreachable: exit 2, nothing recorded."""


@dataclass(frozen=True)
class PrInfo:
    url: str
    state: str                              # open | merged | closed
    merged: bool
    merge_commit: str
    head_sha: str
    author: str
    approvals: tuple[tuple[str, str], ...]  # (login, commit the approval was made on; "" when unknown)

def _run(host: str, argv: list[str], cwd: Path) -> Any:
    executable = shutil.which(_EXECUTABLE[host])
    if executable is None:
        raise HostUnavailable(f"{_EXECUTABLE[host]} is not installed; install it, then run {_LOGIN_FIX[host]}")
    try:
        completed = subprocess.run([executable, *argv], cwd=cwd, text=True, capture_output=True, check=False,
                                   timeout=60)
    except (OSError, subprocess.SubprocessError) as error:
        raise HostUnavailable(f"{_EXECUTABLE[host]} failed: {error}") from error
    if completed.returncode != 0:
        raise HostUnavailable(f"{_EXECUTABLE[host]} {argv[0]} failed: {completed.stderr.strip()} "
                              f"(check `{_LOGIN_FIX[host]}`)")
    try:
        return json.loads(completed.stdout or "null")
    except json.JSONDecodeError as error:
        raise HostUnavailable(f"{_EXECUTABLE[host]} returned non-JSON output") from error


def _github(url: str, cwd: Path) -> PrInfo:
    data = _run("github", ["pr", "view", url, "--json",
                           "url,state,mergeCommit,headRefOid,author,reviews,files,body"], cwd)
    latest: dict[str, tuple[str, str]] = {}
    for review in data.get("reviews") or []:
        state = review.get("state", "")
        if state in ("APPROVED", "CHANGES_REQUESTED", "DISMISSED"):
            login = (review.get("author") or {}).get("login", "")
            latest[login] = (state, (review.get("commit") or {}).get("oid", ""))
    state = str(data.get("state", "")).lower()
    return PrInfo(
        url=data.get("url", url),
        state=state,
        merged=state == "merged",
        merge_commit=(data.get("mergeCommit") or {}).get("oid", ""),
        head_sha=data.get("headRefOid", ""),
        author=(data.get("author") or {}).get("login", ""),
        approvals=tuple((login, commit) for login, (review_state, commit) in latest.items()
                        if review_state == "APPROVED"),
        files=tuple(item.get("path", "") for item in data.get("files") or []),
        body=data.get("body") or "",

def _gitlab_ref(url: str) -> tuple[str, str]:
    parsed = urlparse(url)
    project, marker, rest = parsed.path.strip("/").partition("/-/merge_requests/")
    if not marker or not rest.split("/")[0].isdigit():
        raise HostUnavailable(f"not a GitLab merge request URL: {url}")
    return f"{parsed.scheme}://{parsed.netloc}/{project}", rest.split("/")[0]

    repo, iid = _gitlab_ref(url)
    host = urlparse(url).netloc
    data = _run("gitlab", ["mr", "view", iid, "-R", repo, "-F", "json"], cwd)
    base = f"projects/{data['project_id']}/merge_requests/{iid}"
    approvals = _run("gitlab", ["api", "--hostname", host, f"{base}/approvals"], cwd)
    changes = _run("gitlab", ["api", "--hostname", host, f"{base}/changes"], cwd)

        files=tuple(item.get("new_path", "") for item in changes.get("changes") or []),
        body=data.get("description") or "",
    )


def fetch_pr(url: str, host: str, cwd: Path) -> PrInfo:
    return _github(url, cwd) if host == "github" else _gitlab(url, cwd)

```python
"""`gin-workflow team init`: CODEOWNERS, PR/MR template, commit-msg hook, and optional CI per host."""

from __future__ import annotations

from pathlib import Path
import shutil
import subprocess
from typing import Any, Mapping

from .atomic import atomic_write_many
from .specs import render, sdd_config, template_text
from .team import TeamConfig

MARKER = "generated by gin-workflow team init"
_FILES = {
    "github": {"codeowners": ".github/CODEOWNERS", "template": ".github/pull_request_template.md",
               "ci": ".github/workflows/gin-workflow.yml", "ci_template": "team/github-ci.yml"},
    "gitlab": {"codeowners": ".gitlab/CODEOWNERS", "template": ".gitlab/merge_request_templates/Default.md",
               "ci": ".gitlab/ci/gin-workflow.yml", "ci_template": "team/gitlab-ci.yml"},
}
HOOK = ".githooks/commit-msg"


def codeowners_path(team: TeamConfig) -> str:
    return _FILES[team.host]["codeowners"]


def _logins(team: TeamConfig, roles: set[str]) -> list[str]:
    return sorted(f"@{member.login}" for member in team.members.values() if roles & set(member.roles))


def codeowners(team: TeamConfig, config: Mapping[str, Any]) -> str:
    """Area globs owned by the area lead; plan and spec folders owned by the approvers of those gates."""
    lines = [f"# {MARKER}; edit team: in .agent-workflow/config.yaml and rerun", ""]
    leads = {area.lead for area in team.areas.values()}
    for area in team.areas.values():
        owners = _logins(team, {area.lead})
        lines += [f"/{glob} {' '.join(owners)}" for glob in area.paths]
    artifacts = config.get("artifacts") if isinstance(config.get("artifacts"), Mapping) else {}
    cfg = sdd_config(config)
    spec_dirs = [cfg["specs"], cfg["changes"]] if cfg["layout"] == "sdd" else [".planning/specs"]
    requirement = team.approvals.get("requirement_confirmed", [])
    spec_roles = (set(requirement) if isinstance(requirement, list) else set()) | leads
    for directory, roles in ([(artifacts.get("plans", ".planning/plans"), leads)]
                             + [(directory, spec_roles) for directory in spec_dirs]):
        owners = _logins(team, roles)
        if owners:
            lines.append(f"/{str(directory).strip('/')}/ {' '.join(owners)}")
    return "\n".join(lines) + "\n"


def planned_files(root: Path, team: TeamConfig, config: Mapping[str, Any], *, ci: bool) -> dict[str, str]:
    names = _FILES[team.host]
    values = {"convention": team.commit_convention}
    files = {
        names["codeowners"]: codeowners(team, config),
        names["template"]: template_text(root, "team/pull_request_template.md"),
        HOOK: render(template_text(root, "team/commit-msg"), values),
    }
    if ci:
        files[names["ci"]] = render(template_text(root, names["ci_template"]), values)
    return files


def init(root: Path, team: TeamConfig, config: Mapping[str, Any], *, ci: bool = False,
         force: bool = False) -> dict[str, Any]:
    written, skipped, unchanged = [], [], []
    writes: dict[Path, bytes] = {}
    for relative, text in planned_files(root, team, config, ci=ci).items():
        path = Path(root) / relative
        if path.is_file():
            current = path.read_text(encoding="utf-8")
            if current == text:
                unchanged.append(relative)
                continue
            if MARKER not in current and not force:
                skipped.append(relative)
                continue
        writes[path] = text.encode("utf-8")
        written.append(relative)
    hook = Path(root) / HOOK
    if hook in writes:
        atomic_write_many({hook: writes.pop(hook)}, mode=0o755)
    if writes:
        atomic_write_many(writes, mode=0o644)
    return {"written": written, "skipped": skipped, "unchanged": unchanged}


def codeowners_drift(root: Path, team: TeamConfig, config: Mapping[str, Any]) -> bool:
    path = Path(root) / codeowners_path(team)
    return not path.is_file() or path.read_text(encoding="utf-8") != codeowners(team, config)


SHIM = f"""#!/bin/sh
# {MARKER}: commit-msg shim
exec "$(git rev-parse --show-toplevel)/{HOOK}" "$@"
"""


def active_hooks_dir(root: Path) -> Path:
    listed = subprocess.run(["git", "rev-parse", "--git-path", "hooks"], cwd=root, text=True, capture_output=True,
                            check=True).stdout.strip()
    return (Path(root) / listed).resolve()


def hook_active(root: Path) -> bool:
    active = active_hooks_dir(root)
    if active == (Path(root) / ".githooks").resolve():
        return (active / "commit-msg").is_file()
    path = active / "commit-msg"
    return path.is_file() and MARKER in path.read_text(encoding="utf-8", errors="replace")


def install_hook(root: Path) -> dict[str, Any]:
    """Point the active hooks directory (often `.beads/hooks`) at `.githooks/commit-msg` without changing it."""
    if not (Path(root) / HOOK).is_file():
        return {"status": "missing", "path": HOOK}
    active = active_hooks_dir(root)
    if active == (Path(root) / ".githooks").resolve():
        return {"status": "active", "path": HOOK}
    target = active / "commit-msg"
    if target.is_file() and MARKER not in target.read_text(encoding="utf-8", errors="replace"):
        return {"status": "occupied", "path": str(target)}
    active.mkdir(parents=True, exist_ok=True)
    atomic_write_many({target: SHIM.encode("utf-8")}, mode=0o755)
    return {"status": "installed", "path": str(target)}


def _ok(argv: list[str], root: Path) -> bool:
    if shutil.which(argv[0]) is None:
        return False
    try:
        return subprocess.run(argv, cwd=root, capture_output=True, check=False, timeout=30).returncode == 0
    except (OSError, subprocess.SubprocessError):
        return False


def doctor_report(root: Path, team: TeamConfig, config: Mapping[str, Any]) -> dict[str, Any]:
    """`setup doctor` section for team mode: every check plus one fix per failing check."""
    from .team import current_member, has_policy

    cli = {"github": "gh", "gitlab": "glab"}[team.host]
    checks: dict[str, bool] = {
        "member": current_member(root, team) is not None,
        "host_cli": _ok([cli, "auth", "status"], root),
        "codeowners": not codeowners_drift(root, team, config),
    }
    if team.commit_convention != "none":
        checks["hook"] = hook_active(root)
    if has_policy("requirement_confirmed", team):
        checks["spec_review"] = sdd_config(config)["spec_review"] == "pr"
    if team.beads_remote:
        listed = subprocess.run(["bd", "dolt", "remote", "list"], cwd=root, text=True, capture_output=True,
                                check=False) if shutil.which("bd") else None
        checks["beads_remote"] = bool(listed and team.beads_remote in listed.stdout)
        if team.beads_remote.startswith("git+"):
            checks["beads_remote"] = checks["beads_remote"] and _ok(
                ["git", "ls-remote", "--heads", team.beads_remote[4:]], root)
    fixes = {
        "member": "add your git user.email to team.members, or fix `git config user.email`",
        "host_cli": f"install {cli} and run `{cli} auth login`",
        "codeowners": "run `gin-workflow team init` and commit the result",
        "hook": "run `gin-workflow team init` then `gin-workflow team hooks`",
        "spec_review": "set artifacts.spec_review: pr (requirement_confirmed needs PR approval)",
        "beads_remote": f"run `bd dolt remote add origin {team.beads_remote}` and `gin-workflow team sync`",
    }
    report: dict[str, Any] = {"checks": checks, "actions": [fixes[name] for name, ok in checks.items() if not ok]}
    if team.host == "gitlab":
        report["note"] = "GitLab Free cannot require code-owner approval; the gin-workflow check still applies"
    return report

"""Team Beads operations: my ready work, claims, cross-member placeholders, optional Dolt sync."""

from __future__ import annotations

import json
import os
from pathlib import Path
import re
import shutil
import subprocess
from typing import Any

from .team import Member, TeamConfig, TeamError

_EXTERNAL = re.compile(r"^external: (\S+)#(\d+)$")
_PLAN_LINE = re.compile(r"^Plan:\s*`?([^`\s]+)`?\s*$", re.M)
_TRACKS_LINE = re.compile(r"^Tracks:\s*([\d,\s]+)$", re.M)


class SyncConflict(Exception):
    """Dolt reported a merge conflict or a rejected push: exit 1, nothing forced."""


def _bd(root: Path, argv: list[str], *, actor: str = "", timeout: int = 120) -> subprocess.CompletedProcess:
    executable = shutil.which("bd")
    if executable is None:
        raise TeamError("bd is not installed")
    env = {**os.environ, "BD_ACTOR": actor} if actor else None
    return subprocess.run([executable, *argv], cwd=root, text=True, capture_output=True, check=False,
                          env=env, timeout=timeout)


def _bd_json(root: Path, argv: list[str]) -> Any:
    completed = _bd(root, [*argv, "--json"])
    if completed.returncode != 0:
        raise TeamError(f"bd {argv[0]} failed: {completed.stderr.strip()}")
    return json.loads(completed.stdout or "[]")


def _show(root: Path, bead: str) -> dict[str, Any]:
    data = _bd_json(root, ["show", bead])
    return data[0] if isinstance(data, list) else data


def ready(root: Path, team: TeamConfig, member: Member) -> list[dict[str, Any]]:
    mine = set(team.areas_for(member))
    result = []
    for issue in _bd_json(root, ["ready"]):
        assignee = (issue.get("assignee") or "").lower()
        areas = {label[5:] for label in issue.get("labels") or [] if label.startswith("area:")}
        if assignee == member.email or (not assignee and (areas & mine or (not areas and not team.areas))):
            result.append({"id": issue["id"], "title": issue.get("title", ""), "assignee": assignee,
                           "areas": sorted(areas)})
    return result


def sync(root: Path) -> dict[str, Any]:
    for step in ("pull", "push"):
        completed = _bd(root, ["dolt", step])
        if completed.returncode != 0:
            message = (completed.stderr or completed.stdout).strip()
            if step == "pull" and "no branches found" in message:
                continue  # first sync: the remote holds no Beads data yet
            if "conflict" in message.lower() or (step == "push" and "pull" in message.lower()):
                raise SyncConflict(f"bd dolt {step}: {message}")
            raise TeamError(f"bd dolt {step} failed: {message}")
    return {"status": "synced"}


def _dolt_dir(root: Path) -> Path:
    shown = _bd(root, ["dolt", "show"]).stdout
    fields = dict(re.findall(r"^\s*(Database|Mode|Data):\s*(.+?)\s*$", shown, re.M))
    if not fields.get("Mode", "").startswith("embedded") or "Data" not in fields:
        raise TeamError("local Beads is not in embedded mode; reset it to the remote by hand")
    return Path(fields["Data"]) / fields.get("Database", "")


def reset_to_remote(root: Path) -> None:
    """Drop local unpushed Beads commits; callers sync first so only the failed claim is lost."""
    dolt = shutil.which("dolt")
    if dolt is None:
        raise TeamError("dolt is not installed; cannot reset local Beads to the remote")
    directory = _dolt_dir(root)
    for argv in (["fetch", "origin"], ["reset", "--hard", "origin/main"]):
        completed = subprocess.run([dolt, *argv], cwd=directory, text=True, capture_output=True, check=False,
                                   timeout=120)
        if completed.returncode != 0:
            raise TeamError(f"dolt {argv[0]} failed: {completed.stderr.strip()}")


def claim(root: Path, team: TeamConfig, member: Member, bead: str) -> dict[str, Any]:
    if team.beads_remote:
        sync(root)
    holder = (_show(root, bead).get("assignee") or "").lower()
    if holder and holder != member.email:
        raise SyncConflict(f"{bead} is already claimed by {holder}")
    completed = _bd(root, ["update", bead, "--claim"], actor=member.email)
    if completed.returncode != 0:
        raise SyncConflict(completed.stderr.strip() or completed.stdout.strip())
    if team.beads_remote:
        pushed = _bd(root, ["dolt", "push"])
        if pushed.returncode != 0:
            reset_to_remote(root)
            holder = (_show(root, bead).get("assignee") or "").lower() or "nobody"
            raise SyncConflict(f"push rejected; local Beads reset to the remote; {bead} is held by {holder}")
    return {"status": "claimed", "bead": bead, "assignee": member.email}


def _tracks_in(body: str) -> tuple[str, set[int]]:
    plan = _PLAN_LINE.search(body)
    tracks = _TRACKS_LINE.search(body)
    numbers = {int(item) for item in re.findall(r"\d+", tracks.group(1))} if tracks else set()
    return (plan.group(1) if plan else ""), numbers


def _delivers(body: str, plan: str, number: int) -> bool:
    named, numbers = _tracks_in(body)
    return named == plan and number in numbers


def deps(root: Path, team: TeamConfig) -> dict[str, Any]:
    from .team_host import merged_with_text

    closed, waiting = [], []
    for issue in _bd_json(root, ["list", "--status", "open"]):
        match = _EXTERNAL.match(issue.get("title", ""))
        if not match:
            continue
        plan, number = match.group(1), int(match.group(2))
        found = next((pr for pr in merged_with_text(team.host, plan, root) if _delivers(pr.body, plan, number)), None)
        if found is None:
            waiting.append(issue["id"])
            continue
        done = _bd(root, ["close", issue["id"], "--reason", f"{found.url} merged ({found.merge_commit})"])
        if done.returncode != 0:
            raise TeamError(f"bd close {issue['id']} failed: {done.stderr.strip()}")
        closed.append({"id": issue["id"], "pr": found.url})
    return {"closed": closed, "waiting": waiting}

---
name: gin-team
description: Use in a lifecycle stage when `project.team.enabled` is true — member identity, PR-proven gates, track areas and owners, claims, Beads sync.
---

# Team Mode

Applies only when `gin-workflow state --format json` reports `project.team.enabled: true`. `project.team.me` is the member behind `git config user.email`; when it is null this clone cannot record gates or claim tracks: stop and point to `/gin-workflow:team-setup`. Commands are `gin-workflow team <command>`; exit 1 means findings or a rejection to report, exit 2 means an identity, usage, or host problem to fix first.

## Gates
- `record` and `unblock` take the actor from the git email; omit `--actor`.
- A gate with roles in `team.approvals` is recorded with `--evidence <PR/MR URL>`; `record` checks that the PR is merged (open is fine for `verification_passed`) and approved by a member holding a listed role, never by its author. Exit 1 lists the missing approvals: report them to the user. Never switch evidence or waive a gate to get past a rejection.
- `team check --gate <gate> <url>` re-verifies a teammate's gate without recording it.

## discuss
When `team.approvals.requirement_confirmed` lists roles, spec review is `pr`: with `project.layout: sdd` follow the `pr` flow of the `gin-sdd` skill; otherwise commit only the spec file on `spec/<topic>`, push, and open a PR after approval. Record `requirement-confirmed --evidence <pr-url>` once it is merged.

## plan
Each track's Metadata adds `Area: <area>` and, when the lead assigns it, `Owner: <member email>`. A track's files stay inside its area; split a track that crosses areas. `team check-plan <plan>` must exit 0 before asking for approval. With `plan_approved: area_lead` (or roles), commit only the plan on `plan/<topic>`, push, and open a PR; after it merges, record `plan-approved --evidence <pr-url>` (`--plan <path>` when the PR changes several plan files).

## orchestrate
Track beads get `--labels track:<N>,area:<area>` and `--assignee <owner>` when the track has one.
- `team.beads_sync` set: the lead orchestrates once for everyone; run `team sync` before and after.
- Not set: each member creates beads only for tracks they own or unowned tracks in `project.team.me.areas`. A dependency on another member's track becomes a bead titled `external: <plan path>#<N>` that blocks the dependent bead.

## execute
- `team deps` first: it closes `external:` placeholders whose track PR has merged.
- Pick from `team ready` and claim with `team claim <bead>` instead of `bd update --status in_progress`; exit 1 means someone else holds it, so pick another.
- Branch `feat/<epic>-<area>`. Commits follow `team.commit_convention`.
- The PR/MR uses the generated template; fill `Plan:` with the plan path and `Tracks:` with the track numbers exactly, because `team deps` on other machines reads them.
- With `team.beads_sync`, run `team sync` after closing a bead.

## verify
When `team.approvals.verification_passed` lists roles: push the feature branch, open the PR, ask that role to approve the latest commit, then record `verification-passed --evidence <pr-url>`. A commit pushed after the approval needs a new approval.

## ship
Merging follows the host rules (CODEOWNERS, branch protection). With `team.beads_sync`, run `team sync` after closing the beads.
```

3. `gin-workflow team init` (`--ci` adds a CI job); report the files it skipped. Commit on a branch, push, and offer to open a PR.
4. With `beads_sync`: `bd dolt remote add origin <remote>`, then `gin-workflow team sync`.
5. Tell the lead what to enable on the host: branch protection on the base branch requiring a PR with one approval and code-owner review (GitHub "Require review from Code Owners"; GitLab Premium "Code owner approval"). The CI spec and CODEOWNERS step runs only when the repository variable `GIN_WORKFLOW_INSTALL` holds a command that installs gin-workflow.

## Member: join
1. `gin-workflow team whoami` must print your entry; otherwise fix `git config user.email` or ask the lead to add you.
2. `gin-workflow team hooks` (installs the commit-msg hook without replacing Beads hooks).
3. Log in to the host CLI: `gh auth login` or `glab auth login`.
4. With `beads_sync` and no `.beads/` yet: `bd init --remote <remote>`. With an existing `.beads/`, ask before replacing it.
