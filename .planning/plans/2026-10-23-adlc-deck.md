# Plan: ADLC deck

Workflow: adlc-deck
Spec: `.planning/specs/2026-10-23-adlc-deck-design.md`
Bead: gin-workflow-c8ko

## Goal

One slide deck that explains the Agentic Development Lifecycle gin-workflow 2.1 applies, to a developer or team lead new to gin-workflow. It ships as `docs/presentations/adlc.html` (source of truth, offline, keyboard navigation) and `docs/presentations/adlc.pptx` (the same 17 slides, editable shapes).

## Architecture

- The HTML is one static file: slides are `<section class="slide">` elements, a small inline script shows one at a time, and the diagrams are inline SVG.
- The PPTX is built once from the finished HTML's content with python-pptx, run from a throwaway virtualenv outside the repository. Only the `.pptx` is committed.
- `tests/workflow_core/test_adlc_deck.py` ties both files to `docs/concepts/lifecycle.md`. It uses only the standard library and reads the PPTX with `zipfile`.

## Tech Stack

HTML, CSS, inline SVG and vanilla JS. python-pptx 1.0.2, used only to build the file and never imported by the repository. Python `unittest`.

## Global Constraints

Copied from the spec:

- Every stage and gate shown matches the table in `docs/concepts/lifecycle.md`.
- Commands and keys are the ones in `docs/reference/cli.md` and `docs/reference/config.md`.
- Neither format names a provider or a model.
- The deck does not mention solo mode.
- One self-contained HTML file: inline CSS, JS and SVG, no network requests (no external `src`/`href`, system font stacks).
- The PPTX is built once with python-pptx and committed. No build script or dependency is added to the repository.
- Out of scope: a generator script that builds one format from the other, translations, speaker notes, and any change to the lifecycle itself.

## Approach Options

### Option 1: HTML first, then PPTX from its content

- **Summary:** Track 1 finishes and reviews the HTML. Track 2 builds the PPTX from the approved slide text and diagram layout.
- **Pros:** the PPTX copies reviewed content, and each track has its own test cycle.
- **Cons:** the two tracks run one after the other.

### Option 2: one track for both formats

- **Summary:** one track writes both files.
- **Pros:** fewer review rounds.
- **Cons:** the review covers two large deliverables at once, and a content fix has to be made twice before approval.

### Recommended Approach

- **Selected option:** Option 1.
- **Reasoning:** the PPTX depends on reviewed content. Splitting the tracks keeps each review small and lets a reviewer reject either format on its own.

   ```python
   """The ADLC deck stays offline, navigable, linked and in step with the lifecycle doc."""

   from __future__ import annotations

   from pathlib import Path
   import re
   import unittest

   ROOT = Path(__file__).resolve().parents[2]
   LIFECYCLE = ROOT / "docs/concepts/lifecycle.md"
   DECK_HTML = ROOT / "docs/presentations/adlc.html"
   DECK_LINKS = ("presentations/adlc.html",)
   FORBIDDEN = ("codex", "antigravity", "opencode", "gemini", "sonnet", "opus", "haiku", "gpt")
   SLIDES = 17


   def lifecycle_names() -> set[str]:
       """Stage and gate names from the Stages and gates table of the lifecycle doc."""
       names: set[str] = set()
       for line in LIFECYCLE.read_text(encoding="utf-8").splitlines():
           cells = [cell.strip() for cell in line.strip().strip("|").split("|")]
           if len(cells) == 4 and cells[0].startswith("`"):
               names.update((cells[0].strip("`"), cells[2].strip("`")))
       return names


   def names_forbidden_word(text: str) -> list[str]:
       lowered = text.lower()
       return [word for word in FORBIDDEN if re.search(rf"\b{word}", lowered)]


   class TestLifecycleNames(unittest.TestCase):
       def test_reads_five_stages_and_five_gates(self):
           self.assertEqual(
               {"discuss", "plan", "orchestrate", "execute", "ship", "requirement_confirmed", "plan_approved",
                "orchestration_ready", "implementation_complete", "shipped"},
               lifecycle_names(),
           )


   class TestAdlcHtmlDeck(unittest.TestCase):
       def setUp(self):
           self.html = DECK_HTML.read_text(encoding="utf-8")

       def test_shows_every_stage_and_gate(self):
           for name in sorted(lifecycle_names()):
               with self.subTest(name=name):
                   self.assertIn(name, self.html)

       def test_has_seventeen_slides(self):
           self.assertEqual(SLIDES, len(re.findall(r'<section class="slide[" ]', self.html)))

       def test_loads_nothing_from_the_network(self):
           self.assertEqual([], re.findall(r"""(?:src|href)\s*=\s*["']?https?:""", self.html, re.IGNORECASE))

       def test_navigates_by_keyboard(self):
           for key in ("ArrowLeft", "ArrowRight", "Home", "End"):
               with self.subTest(key=key):
                   self.assertIn(f'"{key}"', self.html)

       def test_names_no_provider_or_model(self):
           self.assertEqual([], names_forbidden_word(self.html))


   class TestAdlcDeckLinks(unittest.TestCase):
       def test_readme_and_getting_started_link_the_deck(self):
           for doc in ("README.md", "docs/getting-started.md"):
               text = (ROOT / doc).read_text(encoding="utf-8")
               for target in DECK_LINKS:
                   with self.subTest(doc=doc, target=target):
                       self.assertIn(target, text)


   if __name__ == "__main__":
       unittest.main()
   ```

   ```python
   import zipfile

   DECK_PPTX = ROOT / "docs/presentations/adlc.pptx"
   DECK_LINKS = ("presentations/adlc.html", "presentations/adlc.pptx")


   def pptx_slide_texts() -> list[str]:
       """The text runs of each slide, in slide order."""
       with zipfile.ZipFile(DECK_PPTX) as deck:
           slides = [name for name in deck.namelist() if re.fullmatch(r"ppt/slides/slide\d+\.xml", name)]
           slides.sort(key=lambda name: int(re.search(r"\d+", name).group()))
           return [" ".join(re.findall(r"<a:t>([^<]*)</a:t>", deck.read(name).decode("utf-8"))) for name in slides]


   class TestAdlcPptxDeck(unittest.TestCase):
       def setUp(self):
           self.slides = pptx_slide_texts()
           self.text = " ".join(self.slides)

       def test_shows_every_stage_and_gate(self):
           for name in sorted(lifecycle_names()):
               with self.subTest(name=name):
                   self.assertIn(name, self.text)

       def test_has_seventeen_slides(self):
           self.assertEqual(SLIDES, len(self.slides))

       def test_is_sixteen_by_nine(self):
           with zipfile.ZipFile(DECK_PPTX) as deck:
               presentation = deck.read("ppt/presentation.xml").decode("utf-8")
           size = re.search(r'<p:sldSz cx="(\d+)" cy="(\d+)"', presentation)
           self.assertEqual(16 * int(size.group(2)), 9 * int(size.group(1)))

       def test_has_no_pictures(self):
           with zipfile.ZipFile(DECK_PPTX) as deck:
               self.assertEqual([], [name for name in deck.namelist() if name.startswith("ppt/media/")])

       def test_names_no_provider_or_model(self):
           self.assertEqual([], names_forbidden_word(self.text))
   ```
