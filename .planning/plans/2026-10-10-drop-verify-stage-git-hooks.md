# Plan: Drop the verify stage; enforce quality in git hooks

## Objective
Remove the `verify` stage and `verification_passed` gate so an autonomous `/goal` over an epic reaches `ship` without looping. The mechanical checks move into git hooks (`gin-workflow hooks install|run`). `ship` stops re-running tests and instead runs a few plain ledger/SDD steps. Team PR approval moves to `ship`.

Spec: `.planning/specs/2026-10-10-drop-verify-stage-git-hooks-design.md` (revision 5).

## Goal / Architecture / Tech Stack
- **Goal:** a goal over an epic reaches `ship` and presents options; quality is enforced by hooks (no agent tokens); CI is the backstop.
- **Architecture:** new `workflow_core/hooks.py` (install/status/run + CLI `main`) wired into `cli.py`; router drops the `verify` stage; `lifecycle_cli.py` drops verification derivation and the `verification-passed` recordable gate; `team.py` renames the PR-approval gate `verification_passed` -> `ship`; skills/docs updated; `skills/verify` deleted.
- **Tech stack:** Python 3 stdlib, `unittest`, POSIX `sh` shims, `bash` safety hook. No new dependencies. `plugins/gin-workflow/dist/` is gitignored and generated by `./install.sh`; never edit or commit it.

## Global Constraints (verbatim from the spec)
- R1. Stages are `discuss, plan, orchestrate, execute, ship`. The router goes from satisfied `implementation_complete` straight to `ship`.
- R2. Removed: the `verify` stage, `skills/verify`, `/gin-workflow:verify`, the `verification_passed` gate and its Safety waiver, `record verification-passed`, the `verification.passed` event, `model_tiers.verify`, and the `verify` usage-attribution stage. Old events stay in the store and are ignored (usage attribution still reads them). Kept: `verify_commands`, `verify.checks`, every review-ledger verification action.
- R3. `record verification-passed` and `unblock --gate verification_passed` exit 2 with a message pointing to the hooks. A config still naming `verification_passed` loads with a deprecation warning; `team.approvals.verification_passed` maps to `team.approvals.ship` with a warning. `examples/config.full.yaml` is updated.
- R4-R9 (hooks): see spec. Out of scope: CI integration, `verify.mode`, event migration, `ship-check`/hook-run evidence events/new state machine, ledger logic changes, bug `gin-workflow-il4`.
- R10-R14 (ship, team, review checklist, docs): see spec.

## Approach
Recommended: three tracks on one integration branch, sequential, in the main session (3 tracks, dependent, no qualifying worker condition).
- Track 1 is additive and shippable alone.
- Track 2 is the code removal plus team rename (the gate and its team approval must change together so team mode never ships unapproved).
- Track 3 is skills, docs, and the remaining tests/packaging; it depends on both.
Deviation from the spec's "two tracks": the spec's track B is split into 2 and 3 so a reviewer can reject code and docs independently.
Spec note on R4 ("generalises `install_hook()`") is simplified: the new `hooks.install` reuses only `team_init.active_hooks_dir()`; the team `commit-msg` install is left untouched (no behavior change there).

## Scope
- In scope: spec R1-R14.
- Out of scope: everything listed under "Out of scope" in the spec.

def make_repo(base, *, lint="true", test="true", rigor="standard"):
    root = Path(base)
    git(root, "init", "-q")
    git(root, "config", "user.email", "t@example.com")

class TestHooksInstall(unittest.TestCase):
    def setUp(self):
        self.tmp = tempfile.TemporaryDirectory()
        self.root = make_repo(self.tmp.name)

    def tearDown(self):
        self.tmp.cleanup()

    def test_install_is_idempotent(self):
        first = hooks.install(self.root)
        self.assertEqual("installed", first["status"])
        self.assertEqual({"pre-commit": "installed", "pre-push": "installed"}, first["hooks"])
        hook = self.root / ".git/hooks/pre-push"
        self.assertEqual(0o755, hook.stat().st_mode & 0o777)
        self.assertIn("hooks run pre-push", hook.read_text())

        self.assertEqual({"pre-commit": "unchanged", "pre-push": "unchanged"}, again["hooks"])

    def test_foreign_hook_is_kept(self):
        foreign = self.root / ".git/hooks/pre-commit"
        foreign.write_text("#!/bin/sh\necho mine\n")
        result = hooks.install(self.root)
        self.assertEqual("occupied", result["status"])
        self.assertEqual("occupied", result["hooks"]["pre-commit"])
        self.assertEqual("installed", result["hooks"]["pre-push"])
        self.assertEqual("#!/bin/sh\necho mine\n", foreign.read_text())

"""Git hooks that run the project's verify commands without an agent (replaces the verify stage)."""

from __future__ import annotations

import argparse
import os
from pathlib import Path
import subprocess
import sys
from typing import Sequence

from .atomic import atomic_write_many
from .configuration import resolve_effective_config
from .project import project_settings
from .team_init import active_hooks_dir

MARKER = "generated by gin-workflow hooks install"
HOOKS = ("pre-commit", "pre-push")
_PRE_COMMIT = ("lint", "typecheck")
_PRE_PUSH = {"easy": ("test",), "standard": ("test", "build"), "strict": ("test", "build", "e2e")}
_GIT_ENV = ("GIT_DIR", "GIT_WORK_TREE", "GIT_INDEX_FILE", "GIT_PREFIX", "GIT_OBJECT_DIRECTORY", "GIT_COMMON_DIR")


def _shim(hook: str) -> str:
    return (f"#!/bin/sh\n# {MARKER}: {hook}\n"
            f'command -v gin-workflow >/dev/null 2>&1 || {{ echo "gin-workflow is not on PATH; run ./install.sh" >&2; exit 1; }}\n'
            f'exec gin-workflow hooks run {hook} "$@"\n')


def install(root: Path) -> dict:
    active = active_hooks_dir(Path(root))
    if not active.is_dir():
        return {"status": "missing", "path": str(active), "hooks": {}}
    result: dict[str, str] = {}
    for hook in HOOKS:
        target, content = active / hook, _shim(hook)
        current = target.read_text(encoding="utf-8", errors="replace") if target.is_file() else None
        if current is not None and MARKER not in current:
            result[hook] = "occupied"
        elif current == content:
            result[hook] = "unchanged"
        else:
            atomic_write_many({target: content.encode("utf-8")}, mode=0o755)
            result[hook] = "installed"
    return {"status": "occupied" if "occupied" in result.values() else "installed",
            "path": str(active), "hooks": result}


def status(root: Path) -> dict[str, str]:
    active, out = active_hooks_dir(Path(root)), {}
    for hook in HOOKS:
        target = active / hook
        if not target.is_file():
            out[hook] = "missing"
        else:
            out[hook] = "ok" if MARKER in target.read_text(encoding="utf-8", errors="replace") else "occupied"
    return out


def _tests_head(root: Path, refs: Sequence[str]) -> bool:
    """True when a pushed ref is a non-delete branch whose local sha is the checked-out HEAD."""
    head = subprocess.run(["git", "rev-parse", "HEAD"], cwd=root, text=True, capture_output=True,
                          check=False).stdout.strip()
    for line in refs:
        parts = line.split()
        if len(parts) == 4 and parts[0].startswith("refs/heads/") and parts[1] == head and set(parts[1]) != {"0"}:
            return True
    return False


def run(root: Path, hook: str, refs: Sequence[str] = ()) -> int:
    root = Path(root)
    settings = project_settings(resolve_effective_config(root, write=False).config.to_dict())
    if hook == "pre-push":
        if not _tests_head(root, refs):
            print("gin-workflow: pre-push tested nothing (no pushed branch at the checked-out HEAD)", file=sys.stderr)
            return 0
        names = _PRE_PUSH.get(settings.rigor, _PRE_PUSH["standard"])
    else:
        names = _PRE_COMMIT
    commands = [(name, settings.verify_commands[name]) for name in names if settings.verify_commands.get(name)]
    if not commands:
        print(f"gin-workflow: no verify commands configured for {hook}; nothing to run", file=sys.stderr)
        return 0
    env = {key: value for key, value in os.environ.items() if key not in _GIT_ENV}
    for name, command in commands:
        print(f"gin-workflow {hook}: {name}: {command}", file=sys.stderr)
        completed = subprocess.run(command, shell=True, cwd=root, env=env)
        if completed.returncode != 0:
            print(f"gin-workflow {hook}: {name} failed (exit {completed.returncode})", file=sys.stderr)
            return completed.returncode
    return 0


def main(argv: Sequence[str]) -> int:
    parser = argparse.ArgumentParser(prog="gin-workflow hooks")
    parser.add_argument("action", choices=("install", "run"))
    parser.add_argument("hook", nargs="?", choices=HOOKS)
    parser.add_argument("--repository", type=Path, default=Path.cwd())
    args = parser.parse_args(list(argv))
    root = args.repository.resolve()
    if args.action == "install":
        result = install(root)
        for hook, state in result["hooks"].items():
            print(f"{hook}: {state}")
        if result["status"] == "missing":
            print(f"hooks directory {result['path']} does not exist; create it or fix core.hooksPath", file=sys.stderr)
        if result["status"] == "occupied":
            print('add `exec gin-workflow hooks run <hook> "$@"` to the existing hook to chain it', file=sys.stderr)
        return {"installed": 0, "occupied": 1, "missing": 2}[result["status"]]
    if args.hook is None:
        parser.error("run needs a hook name")
    refs = [] if sys.stdin.isatty() else sys.stdin.read().splitlines()
    return run(root, args.hook, refs)
