# Plan: Upkeep for one maintainer

Epic: gin-workflow-upkeep
Spec: `.planning/specs/2026-11-27-upkeep-design.md`

## Objective

A weekly upstream check files one `upstream` bead when the Claude Code changelog or a Beads release names a surface gin uses, or when a source cannot be read. `gin hooks uninstall` removes the git hooks gin installed. The Releasing section of `docs/contributing.md` is the one release procedure, and `docs/guides/leaving-gin.md` (with its Vietnamese twin) says what keeps working without gin.

## Global Constraints

Copied from the spec:

- The maintainer's machine is on at the scheduled time. A week whose run did not happen shows in the cron log; the next run reads everything since the last version it read, so nothing is skipped.
- Beads release candidates count: Beads 1.4.0 is breaking and shipped as release candidates first. They are marked as such in the bead.
- `.agent-workflow/runtime/` is git-ignored and local, so the last versions read are local to the machine that runs the check.
- The check reads two public URLs without a token: `https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md` and `https://api.github.com/repos/gastownhall/beads/releases`. One unauthenticated call per week is far below GitHub's limit of 60 per hour.
- In team mode nothing changes for members: the check and the release procedure are the maintainer's. The guide covers the files `gin team init` writes, and `gin hooks uninstall` leaves the team `commit-msg` hook alone, because that hook needs no `gin`.
- Out of scope: freezing or removing any mode or feature; acting on what the check finds; a Claude Code cloud scheduled task; the other harness builds; the marketplace install problems (bead `gin-workflow-6ujv`).

## Route Rubric
- Choose the weakest model that can do the work.
- Raise the model for broad context or design judgement.
- Raise the effort for intrinsic difficulty: intricate logic, many edge cases, or long chains of steps.

| Kind of work | Model | Effort |
|---|---|---|
| Mechanical edits, documentation, boilerplate | weakest | `low` |
| Bounded implementation with a clear spec | middle | `medium` |
| Cross-module change, security, migration, concurrency | strongest | `high` |

Unclear requirements never raise the model or effort.

## Requirement Analysis
- Problem statement: two upstream changes that touch gin (the reserved `ship` name in Claude Code 2.1.330, the one-way Beads 1.4.0 migration) were found by chance; the release steps disagree across four sources; a project that drops gin has every commit and push blocked by the gin hooks.
- Success criteria: the tests of the spec's Testing section pass; `gin docs check` passes on every changed page; `mkdocs build --strict` passes; the maintainer's crontab holds the weekly line and the `github-pages` environment allows `v*` tags.
- Constraints: the Global Constraints above. No stage skill changes, so the stage-chain budgets are untouched.
- Non-goals: see Global Constraints.

## Approach Options
### Option 1: a script in `scripts/` plus one `gin hooks` action
- Summary: `scripts/upstream_watch.py` (standard library only, not shipped in the plugin) with injectable fetch and filing functions for tests; `gin hooks uninstall` next to `install` in `workflow_core/hooks.py`; docs written from the code.
- Pros: maintainer tooling stays out of the plugin; tests run without network; the uninstall reuses the marker check `install` already uses.
- Cons: the surface list is hand-kept; the guard test covers only `bd` calls with a literal subcommand.

### Option 2: a `gin upstream` command in the plugin
- Summary: the same check as a `gin` subcommand.
- Pros: one entry point.
- Cons: every user gets a maintainer tool; rejected in discuss.

### Recommended Approach
- Selected option: Option 1, the design confirmed in discuss.
- Rationale: the plugin surface does not grow, and the check needs no harness.

Decisions this plan takes against the spec text, for the user to confirm with the plan:
- The spec's guard test ("names every `bd` subcommand that `workflow_core` calls") reads the call sites with a literal subcommand: `_bd(...)`, `_beads_json(...)`, and `["bd", ...]` lists. A subcommand built at run time is not seen.
- `gin hooks uninstall` exits 1 when a chained hook still calls `gin`, so a script sees that leaving gin is not finished; otherwise it exits 0.
- Track 4 is a human gate: the maintainer adds the cron line and allows `v*` tags for the `github-pages` environment, or approves the session to run the two commands.
- `docs/changelog.md` is not edited: the changelog is written at release time.

## Scope
- In scope: `scripts/upstream_watch.py` (new), `scripts/upstream_surfaces.json` (new), `tests/test_upstream_watch.py` (new), `plugins/gin-workflow/src/scripts/workflow_core/hooks.py`, `tests/workflow_core/test_hooks.py`, `docs/reference/cli.md`, `docs/contributing.md`, `docs/guides/leaving-gin.md` (new), `docs/guides/leaving-gin.vi.md` (new), `mkdocs.yml`, `README.md`, `.planning/knowledge/release-versioning.md`.

   import importlib.util
   import io
   import json
   from pathlib import Path
   import tempfile
   import unittest

   ROOT = Path(__file__).resolve().parents[1]
   spec = importlib.util.spec_from_file_location("upstream_watch", ROOT / "scripts/upstream_watch.py")
   upstream_watch = importlib.util.module_from_spec(spec)

   ## 2.1.12

   - Added a `PreCompact` hook matcher
   - Faster startup

   ## 2.1.11

   - Reserved the /ship command name
   - Fixed a typo

   ## 2.1.10

   - Changed how plugin skills load
   """
   RELEASES = [
       {"tag_name": "v1.4.0-rc.2", "published_at": "2026-11-20T00:00:00Z", "prerelease": True,
        "body": "- Schema v74 migration is one-way\n- New colors"},
       {"tag_name": "v1.3.4", "published_at": "2026-11-04T00:00:00Z", "prerelease": False,
        "body": "- bd update needs --force to take a claim"},
   ]

   class UpstreamWatchTests(unittest.TestCase):
       def setUp(self):
           directory = tempfile.TemporaryDirectory()
           self.addCleanup(directory.cleanup)
           self.state = Path(directory.name) / "runtime/upstream-watch.json"
           self.filed: list[tuple[str, str]] = []

       def fetch(self, url):
           return CHANGELOG if url == upstream_watch.CHANGELOG_URL else json.dumps(RELEASES)

       def run_watch(self, *, fetch=None, dry_run=False):
           out = io.StringIO()
           code = upstream_watch.run(self.state, fetch=fetch or self.fetch,
                                     file_bead=lambda title, text: self.filed.append((title, text)),
                                     surfaces=SURFACES, dry_run=dry_run, out=out)
           return code, out.getvalue()

       def save(self, claude, beads):
           self.state.parent.mkdir(parents=True, exist_ok=True)
           self.state.write_text(json.dumps({"claude-code": claude, "beads": beads}), encoding="utf-8")

           self.assertEqual(0, self.run_watch()[0])
           self.assertEqual([], self.filed)
           self.assertEqual({"claude-code": "2.1.12", "beads": "2026-11-20T00:00:00Z"},

       def test_a_later_run_files_one_bead_with_the_new_matching_lines(self):
           self.save("2.1.10", "2026-11-04T00:00:00Z")
           self.assertEqual(0, self.run_watch()[0])
           [(title, text)] = self.filed
           self.assertEqual("Upstream changes: Claude Code 2.1.11 to 2.1.12; Beads v1.4.0-rc.2", title)
           self.assertIn("Added a `PreCompact` hook matcher (hooks)", text)
           self.assertIn("Reserved the /ship command name (commands)", text)
           self.assertIn("v1.4.0-rc.2 (release candidate)", text)
           self.assertIn("Schema v74 migration is one-way (data)", text)
           for absent in ("Faster startup", "plugin skills", "--force", "New colors"):
               self.assertNotIn(absent, text)
           self.assertEqual({"claude-code": "2.1.12", "beads": "2026-11-20T00:00:00Z"},
                            json.loads(self.state.read_text(encoding="utf-8")))

       def test_no_matching_line_files_nothing_and_advances_the_state(self):
           self.save("2.1.12", "2026-11-04T00:00:00Z")
           quiet = [dict(RELEASES[0], body="- New colors"), RELEASES[1]]
           self.assertEqual(0, self.run_watch(fetch=lambda url: CHANGELOG if "CHANGELOG" in url
                                              else json.dumps(quiet))[0])
           self.assertEqual([], self.filed)
           self.assertEqual("2026-11-20T00:00:00Z", json.loads(self.state.read_text(encoding="utf-8"))["beads"])

       def test_a_source_that_fails_files_a_bead_and_keeps_its_state(self):
           self.save("2.1.10", "2026-11-04T00:00:00Z")

           keywords = {keyword for words in surfaces["beads"].values() for keyword in words}

           self.assertTrue({"show", "list", "update"} <= called, called)
           self.assertEqual([], sorted(name for name in called if f"bd {name}" not in keywords))

       unittest.main()

4. Create `scripts/upstream_watch.py`:

   ```python
   """Weekly check of the Claude Code changelog and the Beads releases against the surfaces gin uses.

   Run from the main checkout: `python3 scripts/upstream_watch.py [--dry-run]`. One run files at most one
   `upstream` bead listing the new lines that name a surface of `scripts/upstream_surfaces.json`, and one bead
   per source it cannot read. The last versions read live in `.agent-workflow/runtime/upstream-watch.json`.
   """

   from __future__ import annotations

   import argparse
   from collections.abc import Callable, Mapping, Sequence
   import json
   from pathlib import Path
   import re
   import subprocess
   import sys
   from typing import Any, TextIO
   import urllib.request

   ROOT = Path(__file__).resolve().parents[1]
   SURFACES = ROOT / "scripts/upstream_surfaces.json"
   CHANGELOG_URL = "https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md"
   RELEASES_URL = "https://api.github.com/repos/gastownhall/beads/releases?per_page=30"
   STATE = Path(".agent-workflow/runtime/upstream-watch.json")
   _HEADING = re.compile(r"^## +(\d+(?:\.\d+)+)\s*$", re.MULTILINE)
   _BD_CALL = re.compile(r'(?:_bd|_beads_json)\s*\([^\[\n]*\[\s*"([a-z][a-z-]*)"|\["bd"\s*,\s*"([a-z][a-z-]*)"')
   _NOT_BD = {"gh"}  # `("bd", "gh")` in executables.py names two tools, not a bd subcommand


   def _version(text: str) -> tuple[int, ...]:
       return tuple(int(part) for part in text.split("."))


   def _lines(body: str) -> list[str]:
       """Release-note lines without list markers; blank lines and headings dropped."""
       return [line.strip().lstrip("-* ").strip() for line in body.splitlines()
               if line.strip() and not line.lstrip().startswith("#")]


   def claude_entries(text: str, last: str | None) -> list[tuple[str, list[str]]]:
       """(version, lines) of each changelog section newer than `last`, newest first."""
       headings = list(_HEADING.finditer(text))
       sections = [(match.group(1), text[match.end():headings[index + 1].start() if index + 1 < len(headings) else len(text)])
                   for index, match in enumerate(headings)]
       if not sections:
           raise ValueError("no `## <version>` heading found")
       return [(version, _lines(body)) for version, body in sections
               if last is None or _version(version) > _version(last)]


   def beads_entries(releases: list[dict[str, Any]], last: str | None) -> list[tuple[str, list[str]]]:
       """(label, lines) of each release published after `last`, newest first; a prerelease is marked."""
       rows = sorted(releases, key=lambda release: str(release.get("published_at") or ""), reverse=True)
       return [(f"{row['tag_name']} (release candidate)" if row.get("prerelease") else str(row["tag_name"]),
                _lines(str(row.get("body") or "")))
               for row in rows if last is None or str(row.get("published_at") or "") > last]


   def matching(lines: list[str], groups: Mapping[str, list[str]]) -> list[tuple[str, list[str]]]:
       """(line, group names) of each line holding a keyword; a keyword needs no letter or digit right before it."""
       found = []
       for line in lines:
           names = [name for name, keywords in groups.items()
                    if any(re.search(r"(?<![A-Za-z0-9])" + re.escape(keyword), line, re.IGNORECASE)
                           for keyword in keywords)]
           if names:
               found.append((line, names))
       return found


   def bd_subcommands(source_dir: Path) -> set[str]:
       """The bd subcommands that gin's Python code names at a call site with a literal subcommand."""
       called: set[str] = set()
       for path in Path(source_dir).rglob("*.py"):
           for match in _BD_CALL.finditer(path.read_text(encoding="utf-8")):
               called.add(match.group(1) or match.group(2))
       return called - _NOT_BD


   def _span(entries: list[tuple[str, list[str]]]) -> str:
       versions = [version.split(" ")[0] for version, _ in entries]
       return versions[0] if len(versions) == 1 else f"{versions[-1]} to {versions[0]}"


   def _digest(sources: list[tuple[str, list[tuple[str, list[str]]], Mapping[str, list[str]]]]) -> tuple[str, str] | None:
       """The title and description of the bead for the matching lines, or None when no line matches."""
       spans, parts = [], []
       for name, entries, groups in sources:
           if not entries:
               continue
           spans.append(f"{name} {_span(entries)}")
           for version, lines in entries:
               hits = matching(lines, groups)
               if hits:
                   parts.append(f"{name} {version}:\n" + "\n".join(f"- {line} ({', '.join(names)})" for line, names in hits))
       if not parts:
           return None
       text = ("Lines of the upstream release notes that name a surface gin uses "
               "(scripts/upstream_surfaces.json). Close the bead when none needs work; split a line that does.\n\n"
               + "\n\n".join(parts))
       return f"Upstream changes: {'; '.join(spans)}", text


   def run(state_path: Path, *, fetch: Callable[[str], str], file_bead: Callable[[str, str], None],
           surfaces: Mapping[str, Mapping[str, list[str]]], dry_run: bool = False, out: TextIO = sys.stdout) -> int:
       """0 when every source was read, 1 when a source failed (its bead filed), 2 when a bead could not be filed."""
       state: dict[str, str] = json.loads(state_path.read_text(encoding="utf-8")) if state_path.is_file() else {}
       first = not state_path.is_file()
       newest, sources, failures = dict(state), [], []
       readers = (("claude-code", "Claude Code", "Claude Code changelog", CHANGELOG_URL,
                   lambda text, last: claude_entries(text, last),
                   lambda text: _HEADING.search(text).group(1)),
                  ("beads", "Beads", "Beads releases", RELEASES_URL,
                   lambda text, last: beads_entries(json.loads(text), last),
                   lambda text: max(str(row.get("published_at") or "") for row in json.loads(text))))
       for key, name, label, url, entries_of, newest_of in readers:
           try:
               text = fetch(url)
               entries = entries_of(text, state.get(key))
               newest[key] = newest_of(text)
           except (OSError, ValueError, KeyError, TypeError, AttributeError) as error:
               failures.append((f"Upstream check could not read {label}",
                                f"{url} failed: {error}. The next run reads the same range again."))
               continue
           sources.append((name, [] if first else entries, surfaces[key]))
       beads = failures + ([] if first or (digest := _digest(sources)) is None else [digest])
       for title, text in beads:
           print(title, file=out)
           if dry_run:
               print(text, file=out)
               continue
           try:
               file_bead(title, text)
           except (OSError, RuntimeError) as error:
               print(f"could not file the bead: {error}", file=sys.stderr)
               return 2
       if not dry_run:
           failed = {title.removeprefix("Upstream check could not read ") for title, _ in failures}
           kept = {key: (state[key] if label in failed and key in state else newest.get(key, state.get(key)))
                   for key, _, label, *_ in readers}
           state_path.parent.mkdir(parents=True, exist_ok=True)
           state_path.write_text(json.dumps({key: value for key, value in kept.items() if value}, indent=2) + "\n",
                                 encoding="utf-8")
       if first:
           print("baseline recorded; the next run reports what changes after it", file=out)
       return 1 if failures else 0


   def _fetch(url: str) -> str:
       request = urllib.request.Request(url, headers={"User-Agent": "gin-upstream-watch",
                                                      "Accept": "application/vnd.github+json"})
       with urllib.request.urlopen(request, timeout=30) as response:
           return response.read().decode("utf-8")


   def _main_checkout() -> Path:
       common = subprocess.run(["git", "rev-parse", "--path-format=absolute", "--git-common-dir"], cwd=ROOT,
                               text=True, capture_output=True, check=True).stdout.strip()
       return Path(common).parent


   def _file_bead(root: Path) -> Callable[[str, str], None]:
       def file_bead(title: str, text: str) -> None:
           done = subprocess.run(["gin", "task", "create", "--type", "task", "-l", "upstream", "-d", text, title],
                                 cwd=root, text=True, capture_output=True)
           if done.returncode:
               raise RuntimeError((done.stderr or done.stdout).strip() or f"gin task create exited {done.returncode}")
       return file_bead


   def main(argv: Sequence[str] | None = None) -> int:
       parser = argparse.ArgumentParser(prog="upstream_watch", description=__doc__.splitlines()[0])
       parser.add_argument("--dry-run", action="store_true", help="print what would be filed; file and write nothing")
       args = parser.parse_args(argv)
       root = _main_checkout()
       surfaces = json.loads(SURFACES.read_text(encoding="utf-8"))
       return run(root / STATE, fetch=_fetch, file_bead=_file_bead(root), surfaces=surfaces, dry_run=args.dry_run)


   if __name__ == "__main__":
       raise SystemExit(main())
   ```

       """Remove the hooks `install` wrote; a hook that chains `gin hooks run` or is someone else's stays."""
       active = active_hooks_dir(Path(root))
       if not active.is_dir():
           return {"status": "missing", "path": str(active), "hooks": {}}
       result: dict[str, str] = {}
       for hook in HOOKS:
           target = active / hook
           current = target.read_text(encoding="utf-8", errors="replace") if target.is_file() else None
           if current is None:
               result[hook] = "absent"
           elif _ours(current):
               target.unlink()
               result[hook] = "removed"
           else:
               result[hook] = "chained" if _RUN in current or _LEGACY_RUN in current else "foreign"
       return {"status": "chained" if "chained" in result.values() else "removed", "path": str(active), "hooks": result}
