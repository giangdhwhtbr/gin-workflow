# Plan: gin-qa interactive HTML report

Epic: gin-workflow-qa-report
Spec: .planning/specs/2026-11-04-qa-report-design.md

## Objective

`gin-qa report [capability]` writes one folder, `qa/evidence/report-<UTC stamp>/` by default, holding an `index.html` that opens offline (CSS, JS, and data inlined) and copies of the e2e screenshots it shows, so QA zips that one folder to share it. The page has four bar charts that filter a searchable case table, and a case detail view with test data, steps, result, run, bug, and the per-step evidence of the case's latest run. `/gin-qa:report` runs it from the agent.

Goal (from the spec): QA needs one report they can open offline and send to someone else: counts per capability, type, priority, and result with charts, and a filterable case list where each case shows its test data, steps, latest result, run evidence, and bug.

Architecture: a new module `plugins/gin-qa/src/scripts/gin_qa/report.py` gathers the data from `cases.load`/`cases.as_dict` and, once per distinct `Run` under the evidence folder, from `e2e.export`; it copies the screenshots into the report folder and writes `index.html` by replacing one placeholder in the shipped template `plugins/gin-qa/src/templates/report.html` with the JSON. The template renders everything in the browser with vanilla JS using DOM calls only. `cli.py` adds a third top-level group, `report`.

Tech Stack: Python 3 stdlib (`json`, `shutil`, `pathlib`, `datetime`) in the gin-qa CLI; HTML, CSS, and vanilla JS in one template file; `unittest` tests run by `python3 -m pytest -n auto`; Markdown skill and docs.

### Global Constraints (verbatim from the spec)

- Out of scope: xlsx output (dropped on 2026-11-04 in favour of HTML); trend history across runs; publishing or uploading the report; runners for non-e2e types; embedding screenshots as base64; ARIA snapshots in the report; a project-overridable report template.
- Case data is embedded as JSON in `<script type="application/json">` with every `<` written as `<`, so no case text can close the script element.
- The page sets text with `textContent` and builds elements with DOM calls; case data never reaches `innerHTML`.
- Only screenshots that `e2e.export` resolved inside the run folder are copied.
- `index.html` refers to images by those relative paths only. Nothing outside the folder is referenced.
- A missing or invalid run folder is not an error: it is listed in `missing_evidence` and shown on the page.
- No new Python or JavaScript dependency. `cases export` and `e2e export` output stays unchanged, so gin-console is not affected.
- Exit codes follow the existing gin-qa contract: 0 written, 2 usage or environment error (unknown capability, no cases, non-empty `--out`, unreadable template). The report itself has no findings, so it never exits 1.

## Requirement Analysis
- Problem statement: `gin-qa cases export` and `gin-qa e2e export` emit JSON only (`cli.py:181-184`, `cli.py:208-213`); the QA guide tells users to build their own report from it (`docs/guides/qa.md:50`). Screenshots live in git-ignored run folders (`e2e.py:149-160`), one folder per run (`e2e.py:248-257`), and each case names its latest run in its `Run` line (`e2e.py:_record`).
- Success criteria: spec US-1 to US-5 acceptance criteria; `python3 -m pytest -n auto` green; `bash tests/install_smoke_test.sh` passes; a generated report checked in a browser from a `file://` URL (Track 2, Step 2.3).
- Constraints: Global Constraints above; the `result.json` shape, `cases export`, and `e2e export` are unchanged.
- Non-goals: see Global Constraints, Out of scope.

## Approach Options
### Option 1: Python gathers data, one template renders it
- Summary: `report.py` builds a JSON document and replaces one placeholder in `templates/report.html`; the template's JS draws charts, table, and detail view.
- Pros: least Python; the whole page is one file a frontend reviewer reads alone; no dependency.
- Cons: the page's behaviour is checked in a browser, not by unit tests.

### Option 2: Python renders the HTML, JS only filters
- Summary: Python string-builds rows, charts, and detail blocks; JS shows and hides them.
- Pros: more of the output is unit-testable.
- Cons: HTML escaping in Python for every field; the page structure split across Python strings; harder to change the layout.

### Option 3: Inline a chart library
- Summary: vendor Chart.js into the template.
- Pros: richer charts.
- Cons: about 200 KB more per report and a third-party license for four bar charts.

### Recommended Approach
- Selected option: Option 1 (chosen in `/discuss`).
- Rationale: one owner per concern: `report.py` owns data and files, the template owns presentation; the only trust boundary (case text into the page) is closed by one escape in Python and a DOM-only rule in JS, both tested.

## Scope
- In scope: spec Requirements (Data, Output, Page, Safety), US-1 to US-5, the `report` group in `cli.py`, the skill, docs, and the gin-qa version bump.
- Out of scope: see Global Constraints.

```python
"""`gin-qa report`: one folder holding an offline HTML report of the test cases and the e2e screenshots it shows."""

from __future__ import annotations

from datetime import datetime, timezone
import json
from pathlib import Path, PurePosixPath
import shutil
from typing import Any

from . import cases as tc
from . import e2e
from .reqs import Effective, QaError

TEMPLATE = "report.html"
PLACEHOLDER = "/*GIN_QA_DATA*/"
RESULT_KEYS = ("project", "status", "error", "started", "finished")
STEP_KEYS = ("n", "title", "status", "url", "error")

Results = dict[str, list[dict[str, Any]]]


def _run_results(root: Path, eff: Effective, run: str) -> tuple[str, Results] | None:
    """(the run folder as `e2e export` shows it, results per case ID), or None when the folder cannot be read."""
    try:
        payload = e2e.export(root, eff, run)
    except (QaError, OSError, ValueError):
        return None
    return payload["run"], {row["id"]: row["results"] for row in payload["cases"]}


def _result(data: dict[str, Any], run: str, copies: dict[str, str]) -> dict[str, Any]:
    """One Playwright project's result; each screenshot gets its path inside the report folder, `<run name>/...`."""
    steps = []
    for step in data.get("steps", []):
        if not isinstance(step, dict):
            continue
        shot, target = step.get("screenshot"), None
        if isinstance(shot, str):  # e2e.export keeps only files resolved inside the run folder
            target = (PurePosixPath(PurePosixPath(run).name) / PurePosixPath(shot).relative_to(run)).as_posix()
            copies[shot] = target
        steps.append({**{key: step.get(key) for key in STEP_KEYS}, "screenshot": target})
    return {**{key: data.get(key) for key in RESULT_KEYS}, "steps": steps}


def _target(root: Path, eff: Effective, out: str | None) -> Path:
    """The report folder, not created yet: `out` (missing or empty), else a new `<evidence>/report-<stamp>`."""
    if out is not None:
        path = (root / out).resolve()
        if path.exists() and (not path.is_dir() or any(path.iterdir())):
            raise QaError(f"{out}: exists and is not an empty folder")
        return path
    base = root / e2e.evidence_root(eff)
    stamp = datetime.now(timezone.utc).strftime("%Y-%m-%dT%H-%M-%S")
    path, suffix = base / f"report-{stamp}", 2
    while path.exists():
        path, suffix = base / f"report-{stamp}-{suffix}", suffix + 1
    return path


def build(root: Path, eff: Effective, capability: str | None, out: str | None) -> dict[str, Any]:
    """Writes `index.html` and the screenshots it shows into a new folder; returns what the CLI prints."""
    cases, _ = tc.load(root, eff.cases_dir)  # parse findings are `gin-qa cases check`'s job
    if capability is not None:
        cases = [case for case in cases if case.cap == capability]
    if not cases:
        raise QaError(f"no test cases for capability {capability}" if capability
                      else f"no test cases under {eff.cases_dir}")
    template = e2e._template(TEMPLATE).read_text(encoding="utf-8")
    if template.count(PLACEHOLDER) != 1:
        raise QaError(f"the {TEMPLATE} template must hold {PLACEHOLDER} once; reinstall gin-qa")
    folder = _target(root, eff, out)
    evidence = f"{e2e.evidence_root(eff)}/"
    runs: dict[str, tuple[str, Results] | None] = {}
    copies: dict[str, str] = {}
    rows = []
    for case in cases:
        row = {**tc.as_dict(case), "evidence": "none", "results": []}
        run = row["run"]
        if run.startswith(evidence):  # anything else is a manual run reference, shown as text
            if run not in runs:
                runs[run] = _run_results(root, eff, run)
            found = runs[run]
            row["evidence"] = "missing" if found is None else "found"
            if found is not None:
                shown, by_id = found
                row["results"] = [_result(data, shown, copies) for data in by_id.get(case.id, [])]
        rows.append(row)
    # ponytail: a second report in the same second exits 2 if it loses the mkdir race; no lock needed
    folder.mkdir(parents=True, exist_ok=out is not None)
    for source, target in copies.items():
        (folder / target).parent.mkdir(parents=True, exist_ok=True)
        shutil.copyfile(root / source, folder / target)
    data = {"generated": datetime.now(timezone.utc).isoformat(timespec="seconds"), "scope": capability,
            "cases": rows}
    index = folder / "index.html"
    index.write_text(template.replace(PLACEHOLDER, json.dumps(data, sort_keys=True).replace("<", "\\u003c")),
                     encoding="utf-8")
    return {"report": index.relative_to(root).as_posix() if root in index.parents else str(index),
            "cases": len(rows), "screenshots": len(copies),
            "missing_evidence": [run for run, found in runs.items() if found is None]}
```

(() => {
  'use strict';
  // Case text is rendered with textContent and setAttribute only; never parse it as HTML.
  const data = JSON.parse(document.getElementById('gin-qa-data').textContent);
  const cases = data.cases;
  const DIMS = [['capability', 'Capability'], ['type', 'Type'], ['priority', 'Priority'], ['result', 'Result']];
  const filters = { capability: '', type: '', priority: '', result: '' };
  const $ = (id) => document.getElementById(id);
  const value = (item, dim) => item[dim] || '(none)';
  const tone = (result) => ({ passed: 'passed', failed: 'failed', blocked: 'blocked' })[result] || 'notrun';

  function el(tag, props, ...children) {
    const node = document.createElement(tag);
    for (const [key, val] of Object.entries(props || {})) {
      if (key === 'text') node.textContent = val;
      else if (key.startsWith('on')) node.addEventListener(key.slice(2), val);
      else node.setAttribute(key, val);
    }
    for (const child of children) if (child !== null && child !== undefined) node.append(child);
    return node;
  }
  const badge = (result) => el('span', { class: `badge ${tone(result)}`, text: result });

  function counts(dim) {
    const map = new Map();
    for (const item of cases) map.set(value(item, dim), (map.get(value(item, dim)) || 0) + 1);
    return [...map].sort((a, b) => b[1] - a[1] || a[0].localeCompare(b[0]));
  }

  function toggle(dim, name) {
    filters[dim] = filters[dim] === name ? '' : name;
    update();
  }

  function renderCharts() {
    $('charts').replaceChildren(...DIMS.map(([dim, label]) => {
      const rows = counts(dim);
      const max = Math.max(...rows.map(([, count]) => count));
      return el('section', { class: 'chart' }, el('h2', { text: label }), ...rows.map(([name, count]) => {
        const fill = el('span', { class: 'fill' });
        fill.style.width = `${(count / max) * 100}%`;
        if (dim === 'result') fill.style.background = `var(--${tone(name)})`;
        return el('button', {
          type: 'button', class: 'bar', 'aria-pressed': String(filters[dim] === name),
          title: `${label}: ${name} (${count})`, onclick: () => toggle(dim, name),
        }, el('span', { class: 'name', text: name }), el('span', { class: 'track' }, fill),
        el('span', { class: 'count', text: String(count) }));
      }));
    }));
  }

  function renderSelects() {
    for (const [dim, label] of DIMS) {
      $('filters').append(el('select', {
        id: `filter-${dim}`, 'aria-label': label,
        onchange: (event) => { filters[dim] = event.target.value; update(); },
      }, el('option', { value: '', text: `${label}: all` }),
      ...counts(dim).map(([name]) => el('option', { value: name, text: name }))));

  }

  function shown() {
    const query = $('search').value.trim().toLowerCase();
    return cases.filter((item) => DIMS.every(([dim]) => !filters[dim] || value(item, dim) === filters[dim])
      && (!query || item.id.toLowerCase().includes(query) || item.title.toLowerCase().includes(query)));
  }

  function renderTable() {
    const rows = shown();

    el('td', { text: item.type }), el('td', { text: item.priority }), el('td', {}, badge(item.result)),
    el('td', { text: item.bug }))));
  }

  function update() {
    for (const [dim] of DIMS) $(`filter-${dim}`).value = filters[dim];
    renderCharts();
    renderTable();
  }

  const list = (items, ordered) => el(ordered ? 'ol' : 'ul', {}, ...items.map((item) => el('li', { text: item })));
  const part = (title, ...content) => el('section', {}, el('h3', { text: title }), ...content);

  function step(item) {
    const li = el('li', {}, el('div', {}, badge(item.status), ` ${item.title || ''}`),
      item.url ? el('div', { class: 'muted url', text: item.url }) : null,
      item.error ? el('div', { class: 'warn', text: item.error }) : null);
    if (item.screenshot) {
      const href = `./${item.screenshot}`; // a path inside the report folder; the ./ keeps it from reading as a URL scheme
      li.append(el('a', { href, target: '_blank', rel: 'noopener' },
        el('img', { src: href, alt: `Screenshot after step ${item.n}`, loading: 'lazy' })));
    }
    return li;
  }

  function evidence(item) {
    if (item.evidence === 'missing') return [el('p', { class: 'warn', text: `evidence not found: ${item.run}` })];
    if (item.evidence === 'none') return [el('p', { class: 'muted', text: 'No e2e run evidence.' })];
    if (!item.results.length) return [el('p', { class: 'muted', text: `No result for this case in ${item.run}.` })];
    return item.results.map((result) => el('div', { class: 'result' },
      el('h4', {}, `${result.project || 'Default project'} `, badge(result.status)),
      result.error ? el('p', { class: 'warn', text: result.error }) : null,
      el('ol', { class: 'run-steps' }, ...result.steps.map(step))));
  }

  function openCase(item) {
    const facts = [['Capability', item.capability], ['Type', item.type], ['Priority', item.priority],
      ['REQ', item.reqs.map((req) => `${req.id}@${req.hash8}`).join(', ')], ['Source', item.source],
      ...Object.entries(item.fields), ['Result', item.result], ['Run', item.run], ['Bug', item.bug],
      ['File', `${item.file}:${item.line}`]];
    const details = el('dl', {});
    for (const [key, val] of facts) if (val) details.append(el('dt', { text: key }), el('dd', { text: val }));
    const parts = [el('h2', { text: `${item.id}: ${item.title}` }), details];
    for (const [title, items, ordered] of [['Preconditions', item.preconditions], ['Test data', item.test_data],
      ['Steps', item.steps, true], ['Expected', item.expected]]) {
      if (items.length) parts.push(part(title, list(items, ordered)));
    }
    parts.push(part('Run evidence', ...evidence(item)));
    $('detail-body').replaceChildren(...parts);
    $('detail').showModal();
  }

  $('detail').addEventListener('click', (event) => { if (event.target === $('detail')) $('detail').close(); });
  const scope = data.scope ? `capability ${data.scope}` : 'all capabilities';
  $('summary').textContent = `${cases.length} cases · ${scope} · generated ${data.generated}`;
  renderSelects();
  update();
})();
</script>
